# Сценарии приёмки

Список проверяемых сценариев по разделам ТЗ. Отметка **[авто]** означает, что сценарий проверяется автоматическими тестами (`tests/run.php`); остальные проверяются вручную в браузере.

## Установка (8.2)
- [ ] `start.php` на чистой базе MySQL 5.7 создаёт таблицы, `include/connect.php` (пароль — хеш), `robots.txt`.
- [ ] Повторное открытие `start.php` — сообщение «CMS уже установлена» (403). **[авто]**
- [ ] В админке — предупреждение удалить `start.php`, пока файл есть. **[авто]**
- [ ] `passhash.php` (скопированный в корень) выдаёт хеш; хеш, вставленный в `$r08`, позволяет войти с новым паролем; пока файл в корне — предупреждение в админке.

## Безопасность и доступ (3, 8.1, 8.3)
- [ ] `/manet` и все страницы админки без входа ведут на форму входа. **[авто]**
- [ ] Неверный пароль — сообщение и счётчик попыток; после 5 неверных попыток вход блокируется на 15 минут. **[авто]**
- [ ] Через 2 часа бездействия требуется повторный вход.
- [ ] Действия без CSRF-токена не выполняются. **[авто]**
- [ ] Cookie сессии: HttpOnly, SameSite, Secure при HTTPS. **[авто, кроме Secure]**
- [ ] Каталоги `include/`, `public/classes`, `public/templates`, `admin/classes`, `admin/templates` недоступны по HTTP (403). **[авто]**
- [ ] PHP-файл в `uploads/` не выполняется. **[авто]**
- [ ] Админка отдаёт `X-Robots-Tag: noindex`; адреса админки нет в `robots.txt`. **[авто]**

## Адрес, телефон, логотип (4.1–4.3, 4.8)
- [ ] Адрес выводится в шапке (Schema.org LocalBusiness / PostalAddress / streetAddress), у формы заявки, в блоке «Как нас найти». **[авто]**
- [ ] Телефон выводится как введён, `href="tel:"` — только цифры и «+»; в шапке, у формы, в «Как нас найти», в призывах к действию. **[авто]**
- [ ] Логотип: PNG/JPG/GIF/WebP; файл другого типа (в т. ч. с подменённым расширением) отклоняется; alt; при замене старый файл удаляется; без логотипа — «Лого» в шапке и подвале. **[авто]**

## Верхнее меню (4.4)
- [ ] Создание пунктов 1 и 2 уровня, ссылка, анкор, title, порядок, активность. **[авто]**
- [ ] Родитель без ссылки раскрывает подпункты; с ссылкой — ссылка в начале выпадающего блока.
- [ ] Неактивный пункт скрыт вместе с подпунктами. **[авто]**
- [ ] Пункт с подпунктами не удаляется (сообщение); удаление — с подтверждением. **[авто]**
- [ ] Подсветка `nav__link--active`: по префиксу адреса, самая длинная ссылка, «/» только на главной, родитель подпункта, на карточке товара — пункт категории. **[авто]**
- [ ] Несколько выпадающих меню работают независимо (наведение, клик, Esc, мобильное меню).

## Слайдер (4.5)
- [ ] Слайды: все поля, порядок, активность, кнопки без текста/ссылки не выводятся. **[авто]**
- [ ] Ровно один h1 — у первого активного слайда. **[авто]**
- [ ] Фото: JPG/PNG/WebP, тип по содержимому, замена и удаление удаляют файл. **[авто]**
- [ ] Нельзя деактивировать или удалить последний активный слайд. **[авто]**
- [ ] Один активный слайд — без стрелок, точек, счётчика и автопрокрутки. **[авто — разметка]**
- [ ] Автопрокрутка вкл/выкл и интервал из админки работают в браузере; счётчик «01 / 03».

## Главная: SEO (4.6)

## Формы заявок (4.7)

- [ ] После отправки — «Ваше сообщение отправлено» и возврат через 3 с на исходную страницу. **[авто]**

- [ ] Отправка через реальный SMTP-сервер хостинга.

## Категории (5.1)
- [ ] Создание, редактирование, удаление с подтверждением; все поля формы; активность по умолчанию включена.
- [ ] Два уровня вложенности, полный путь подкатегории. **[авто]**
- [ ] Удаление запрещено при наличии подкатегорий или товаров; «Без категории» не удаляется, имя не меняется, URL меняется. **[авто]**
- [ ] Свойства товаров: 4 типа, наследование от родителя, предупреждение с количеством товаров при удалении. **[авто]**
- [ ] Неактивная категория скрывает подкатегории и товары (404, нет в sitemap). **[авто]**
- [ ] Страница категории: товары подкатегорий, новые первыми, 36 на странице, `?page=N`, canonical на саму страницу, 404 вне диапазона, `?page=1` → 301. **[авто]**
- [ ] Блок подкатегорий с изображением и названием. **[авто — наличие]**
- [ ] Категория без товаров выводится без блока товаров.
